# Sistema Robótico Colaborativo para Asistencia en Navegación en Interiores Multinivel

> Trabajo de grado — Ingeniería Electrónica

Sistema de robots móviles colaborativos para asistir en la navegación dentro de entornos interiores de múltiples niveles, integrando modelado de entornos, simulación y algoritmos de navegación sobre ROS.

## Requisitos

- Ubuntu 22.04 LTS
- ROS 2 Humble
- Gazebo
- Python 3.10

## Estructura del repositorio

- `Robot/` — Paquetes ROS del robot
- `Documentos/` — Documentación y entregables
- `USTA_WORLD/`, `pasillo_grande/`, `pasillo_usta/` — Entornos de simulación
- Archivos `.world` — Mundos de Gazebo
